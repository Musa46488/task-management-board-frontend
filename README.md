# Task Management Board

A full-stack task management application for organizing work across multiple workflow stages.

## Overview

The Task Management Board allows users to create, update, delete, and move tasks across different workflow states through a responsive interface.

The project is separated into frontend and backend applications.

## Features

- Create, edit, and delete tasks
- Move tasks between workflow stages
- Reorder tasks
- REST API integration
- Responsive task board interface
- PostgreSQL-backed persistence

## Tech Stack

### Frontend
- Next.js
- React
- Tailwind CSS

### Backend
- NestJS
- PostgreSQL
